## 装机时只做这些

在有 Xcode 的 Mac 上，进入候选 host，不要在仓库根目录跑：

```bash
cd apps/testflight_ios
flutter pub get --enforce-lockfile
flutter devices
flutter run --release -d <device_id>
```

装上后拔掉 Mac 线，只留电子琴 USB，再测 S5–S7。失败时把界面原话、是否出设备名、是否出弦乐写进上表。不要先改代码。
