## 粘贴文本

请只测这一件事：用 iPhone 直连一台 USB MIDI 电子琴，练莫扎特钢琴四重奏 K.478。

你在琴上弹钢琴。琴自己出声。App 只播放小提琴、中提琴声部和大提琴，并跟你的速度。中提琴声部当前用的是小提琴音色，这是已知限制。

请按这个顺序：

1. 打开 App，等到「离线弦乐音色已就绪」。
2. 进入 MIDI 排练。不开跟随时，先试播放、暂停、拖动位置、回到开头，以及 0.50×、0.75×、1×、1.25×。停止后不应该有长音。
3. 用转接头把电子琴直接插到 iPhone（不要经过蓝牙或网络 MIDI）。点「开始 MIDI 跟随」。
4. 先故意弹一个错音：弦乐不应该启动。再弹谱上的第一个正确音：弦乐应该跟着走。
5. 钢琴声部单独休止时，弦乐应该继续，不要停下等你。这不是等待模式。
6. 跟随进行中拔出再插上电子琴，看提示是否能懂，再点一次「开始 MIDI 跟随」能不能恢复。
7. 可以打开 21 页钢琴分谱对着看。它不会跟播放自动翻页。

请不要期待，也不要当成缺陷报告：导入自己的 MIDI/PDF、选择其他曲目、麦克风跟随、自动翻页、等待模式、Android。

## 已知限制（写进测试说明，不当 bug）

- 只有 K.478。
- 只验收直连 USB 电子琴。蓝牙、网络、虚拟端点不算通过。
- 中提琴声部用小提琴音色。
- 没有全体等待点。钢琴休止时弦乐继续。
- 分谱不跟播放走。
- 弦乐音色是离线小型 SoundFont，不是交响乐团录音。
