# 能力矩阵与证据边界

> 更新日期：2026-08-06。此表用来防止把“有代码”“有测试”“已真机验证”和“可对外发布”混为一谈。

## 状态定义

- **已实现**：存在受主路径调用的代码。
- **自动化覆盖**：存在针对该能力的测试；不等于真实设备成功。
- **真机证据**：有带 commit、设备、日期和结论的验收记录。
- **可试用**：满足当前范围、资产和发布门槛；不是仅靠代码推断。

| 能力 | 已实现 | 自动化覆盖 | 真机证据 | 可试用 | 事实与边界 |
| --- | --- | --- | --- | --- | --- |
| MIDI 导入、播放、暂停、seek、轨道静音 | 是 | 是 | 待记录 | 待判定 | 基础播放链路存在；真实音色可用性另计。 |
| iOS USB MIDI 设备发现与 Note On 输入 | 是 | Dart 桥接/会话层 | 待记录 | 待判定 | `CoreMidiInputPlugin` 是原生实现；模拟器不能替代外接电子琴验证。 |

## 使用规则

1. 对外文案只能使用“可试用”为“是”的能力。
2. 新功能进入范围前，必须先写入本表，再补实现、自动化测试和真机证据。
3. 真机记录格式见 [`../release_checklist.md`](../release_checklist.md)；资产记录见 [`../evidence/asset_manifest.md`](../evidence/asset_manifest.md)。
