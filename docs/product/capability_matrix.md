# 能力矩阵与证据边界

> 更新日期：2026-08-16。此表防止把“有代码”“有测试”“有设备证据”和“可对外试用”混为一谈。

## 状态定义

- **已实现**：当前代码存在，且注明是否由首页主路径调用。
- **自动化证据**：有对应测试；不等于真实设备已成功。
- **设备证据**：有机型、系统、commit、日期和结论记录。
- **试用状态**：还要同时满足资产、音色、范围和发布门槛。

| 能力 | 已实现/入口 | 自动化证据 | 设备证据 | 试用状态与边界 |
|---|---|---|---|---|
| MIDI 导入与播放 | 是，首页主路径 | 是 | 实体 iPhone 待当轮记录 | 候选；声音来自原 MIDI 时间线 |
| MIDI 自动生成 MusicXML | 是，首页主路径 | converter/service/widget + iOS WKWebView fixture | 实体 iPhone 待记录 | 候选；只承诺练习谱，不是出版谱 |

## 使用规则

1. 对外文案只能描述 [`release_scope.md`](release_scope.md) 纳入且通过当轮发布门槛的能力。
2. 新能力进入核心范围前，先更新范围和本表，再补实现、测试、设备证据与发布清单。
3. 设备记录使用 [`../release_checklist.md`](../release_checklist.md)；资产结论使用 [`../evidence/asset_manifest.md`](../evidence/asset_manifest.md)。
4. 本表记录证据等级，不替代具体测试输出、截图、日志或法律审核。
