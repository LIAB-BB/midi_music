# 当前试用版范围：交互五线谱练习

> 状态：当前产品范围的唯一事实源。更新日期：2026-09-04。
>
> 这是 iOS 封闭试用候选范围，不是公开 App Store 商业发布承诺。实现存在、自动化通过和允许对外分发是三件不同的事。

## 1. 核心用户任务

练习者从根 App 的 K.478 首页打开交互五线谱后：

1. 在同一练习页阅读真实五线谱；
2. 点击任意可映射小节跳转播放位置；
3. 用前后小节、播放/暂停、速度和 AB 循环练习；
4. 对 MIDI 选择钢琴或多个声部组成总谱，并保存本曲/全局默认；
5. 在 50%–140% 间缩放谱面，兼顾浏览密度与细节阅读。

首个内置验收曲目为 Mozart K.478。原 MIDI 是播放真值，自动生成的 MusicXML 只负责显示。通用曲库和 MIDI/MusicXML/PDF 文件导入保留在 `ScoreLibraryPage`，当前默认首页不直接开放。

## 2. 纳入当前核心范围

| 领域 | 当前候选范围 |
|---|---|
| 平台 | iOS 13.6+；真实 iPhone 是最终人工验收设备，模拟器用于自动化和界面检查。 |
| 输入 | 默认路径使用内置 K.478 MIDI；通用 MIDI/MusicXML/PDF 导入属于保留的非默认入口，PDF 仅在配置受控 OMR 服务时进入开发验收。 |
| 乐谱 | 本地 OSMD 连续五线谱、小节点击/高亮/自动滚动、50%–140% 原生重排缩放。 |
| MIDI 记谱 | 默认钢琴双谱表；保留明确 upper/right hand 与 lower/left hand 来源；可多选总谱。 |
| 播放 | SoundFont MIDI 播放、前后小节、播放/暂停、速度和 AB 循环。 |
| 默认 | 本曲具体声部默认与跨曲全局类别默认；换显示谱不重载原 MIDI。 |
| 分发 | 先完成资产、音色、真机和反馈闭环，再决定是否进入小范围 TestFlight。 |

## 3. 当前不承诺

- 自动谱达到出版级排版、真实指法、复杂装饰线编辑或人工校谱质量。
- 从未标注的单轨钢琴中可靠推断真实左右手；此类文件只做可读性启发式分谱。
- 通用 PDF/手写谱/管弦总谱 OMR，或未部署受控服务时的 PDF 导入可用性。
- Android 全量真机质量、云曲库、教师后台、订阅、AI 生成伴奏或商业级管弦音源。
- 把根 App 的交互谱面证据当作独立 TestFlight 候选的 USB、音色或静态分页谱证据，或反向替代。
- 资产台账中未获准分发的 MIDI、PDF、页面图、SoundFont、字体、图片或宣传素材。

## 4. 发布前不可豁免门槛

1. **自动化**：格式化、静态分析、完整测试、iOS no-codesign 构建和 iOS WKWebView/OSMD fixture 全部通过。
2. **资产**：本轮随包、下载或展示的资源均在 [`../evidence/asset_manifest.md`](../evidence/asset_manifest.md) 有证据和明确结论。
3. **音色**：SoundFont 来源、许可证、固定版本/哈希、实际加载路径和失败体验已闭环。
4. **真机**：按 [`../release_checklist.md`](../release_checklist.md) 在实体 iPhone 完成当前入口的谱面、播放、声部、缩放和错误恢复验收。
5. **范围**：root 与独立 TestFlight 候选分别描述和验收，不暗示另一构建目标的能力已经通过。
6. **反馈**：有明确反馈入口、已知问题、暂停测试/回滚条件和负责人。

## 5. 当前试用要回答的问题

| 假设 | 所需证据 | 不通过时的处理 |
|---|---|---|
| MIDI 自动谱足以支持日常分段练习 | K.478 和用户 MIDI 的可读性、错谱类型、完成任务记录 | 优先修记谱边界或引入校对，不扩曲库掩盖问题 |
| 声部选择和默认降低重复设置成本 | 首次选择耗时、重进命中率、错误默认反馈 | 简化面板和默认规则 |
| 小节点击、AB 与缩放改善长曲练习效率 | 跳转/循环/缩放使用频率与失败记录 | 调整控制布局和映射策略 |
| 当前 SoundFont 满足封闭试用 | 同设备同曲目的主观反馈和失败率 | 先解决音色交付与授权，再扩大测试 |

## 6. 两个构建目标

- **root 集成 App**：默认 K.478 首页同时提供交互五线谱和 `PlayerPage` USB MIDI 排练入口；交互谱面按 [`../release_checklist.md`](../release_checklist.md) 验收。
- **独立 TestFlight 候选**：`apps/testflight_ios` + `packages/k478_practice` 只包含固定 K.478、CoreMIDI、随包 Violin/Cello 音色和 21 张静态分页谱，按 [`../releases/k478_testflight_checklist.md`](../releases/k478_testflight_checklist.md) 验收。

两套代码、资产与证据独立。root 的 OSMD/文件导入不进入独立候选；独立候选的静态分页谱和随包 SF2 也不代表 root 已通过对应验收。
