# 产品策略与下一步决策

> 更新日期：2026-08-16。本文定义近期验证顺序，不替代 [`release_scope.md`](release_scope.md) 的当前范围，也不把长期研究写成已承诺功能。

## 1. 当前问题定义

当前最接近真实产品的是：

> 让古典音乐练习者在 iPhone 上把真实 MIDI 快速变成可点击、可缩放、可选声部的练习五线谱，并使用原 MIDI 完成分段播放。

USB MIDI 跟随、通用 OMR、商业音源、曲库订阅和教师功能是独立问题。它们可以成为后续方向，但不能与当前练习页同时被默认视为下一 Sprint 承诺。

## 2. 近期阶段

### 阶段 A：一首曲目的封闭可用性试验

**范围**：iPhone、完成资产核验后的 K.478、当前 SoundFont 交付策略、自动钢琴双谱表、声部总谱、小节点击、AB 和缩放。

**先决条件**：

- 解决或移除未获准分发的随包 MIDI、PDF 页面和 SF2；最终 IPA 与资产台账一致。
- 固定 SoundFont 版本与完整性策略，并保存许可证和实际加载证据。
- 完成实体 iPhone 上的核心发布清单和视觉对照。
- TestFlight 文案只描述当前范围，并明确自动谱和设备限制。

**记录证据**：首次打开时间、生成失败、谱面不可读类型、声部选择理解、小节命中、缩放等待、AB 使用、播放与音色反馈，以及一次完整练习任务能否完成。

**Go/No-Go**：若用户不能稳定完成练习任务，先修记谱、交互或音色；不要用扩曲库、USB 跟随或后端功能掩盖主路径问题。

### 阶段 B：只选择一条主要投资方向

阶段 A 通过后，从以下方向选择一个主要目标：

1. **提高自动谱可读性**：量化、分谱、复杂节奏与可校对工作流。
2. **恢复 USB MIDI 高级演奏台**：先补产品入口，再做实体电子琴、热插拔、轨道静音和长休止基线。
3. **受控 PDF OMR**：补认证、授权、限流、文件防护、数据删除和真实准确率证据后再进入产品范围。
4. **内容与音质**：只用已授权单曲验证固定 SoundFont 或 stem 的音质、体积和交付成本。

这些方向未来可以组合，但不能同时成为下一阶段的完成标准。

### 阶段 C：扩大试用或商业化

- 每一份作品、版次、MIDI、PDF、音色、图片和宣传素材都完成渠道对应的权利记录。
- 有重复使用、任务完成和付费意愿证据后，再决定账号、订阅、教师功能或内容生产投入。
- 对外元数据与能力矩阵一致；重大谱面、音色、崩溃或资产问题有暂停分发和回滚流程。

## 3. 暂停方向与恢复条件

| 方向 | 当前决定 | 恢复条件 |
|---|---|---|
| Android 全量发布 | 暂停 | iOS 主路径验证有价值，并制定独立真机计划 |
| USB MIDI 跟随 | 保留代码，不进核心入口 | 恢复入口并完成真实电子琴基线 |
| PDF OMR | 开发协议，不进默认试用 | 受控服务安全与准确率门槛有证据 |
| stem / 时间拉伸 / 动态层 | 长期研究 | 单曲 vertical slice 达到音质、延迟、体积和许可目标 |
| 云曲库 / 教师 SaaS / 订阅 | 暂停 | 有重复使用和付费证据，且内容权利链闭环 |
