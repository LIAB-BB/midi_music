# 产品策略与路线（经审阅版）

> 更新日期：2026-08-06。此文档替代旧规划中的近期执行承诺；旧报告与长期设想仅保留为历史研究材料。

## 1. 先纠正问题定义

当前最接近真实的产品不是“面向所有独奏乐器的 AI 交响乐团”，而是：

> **让拥有 USB MIDI 电子琴的练习者，在 iPhone 上用一首明确授权、声部明确的室内乐曲目完成无重复钢琴声的跟随伴奏练习。**

这是一个可验证的窄场景。麦克风、任意乐器、动态层、通用乐谱识别、曲库订阅和教师功能各自都是独立产品/研发问题，不能靠同一份路线图默认同时完成。

## 2. 市场考察：已知事实与待验证假设

### 已核验的竞品事实

- [Tomplay](https://tomplay.com/how-it-works) 已提供专业录音伴奏、速度调整、等待模式、循环和注释等练习功能。
- [Metronaut](https://metronautapp.com/what-is-metronaut) 已宣传真实伴奏、等待模式、AI Tempo、即时反馈及多终端练习工具。

因此，“交互乐谱 + 伴奏”不是空白市场，也不能用“竞品没有跟随”作为立项前提。当前可尝试的差异化仅是**低设置成本的 USB MIDI 电子琴工作流、明确的钢琴主导室内乐任务和诚实的试用体验**；它仍需通过用户测试证明价值。

### 必须验证、不得当作事实的假设

1. 目标练习者愿意额外准备 USB 转接器并连接 iPhone。
2. 精确 MIDI 匹配足以覆盖 K.478 的练习节奏，而不会频繁产生误跟随。
3. 用户更在意自动跟随，而非现有产品的专业录音、曲库规模或教学功能。
4. 用户愿意为该窄场景付费，以及合适的收费方式。

## 3. 三段式路线，而非并行堆叠功能

### 阶段 A：一首曲目的封闭可用性试验

**目标**：证明当前 USB MIDI 路径值得继续，而不是证明“正式产品已完成”。

**范围**：iPhone、class-compliant USB MIDI 电子琴、完成资产核验后的 K.478、固定的音色库交付策略。

**先决条件**：

- 解决或移除未使用的随包 SF2；完成其来源与许可记录。
- 从最终 Flutter asset manifest 和 IPA 中排除未授权/无完整证据的曲目与音色；同时移除其对外 UI 入口。仅隐藏或禁用卡片不能消除资源已随包分发的风险；若开发工作区需要保留它们，必须有独立的开发资源配置。
- 把 PDF OMR 明确排除在本次 TestFlight 路径之外，除非先部署有认证、限流、数据删除和端到端验收的服务。
- 完成真实 iPhone + 电子琴的验收记录。

**要记录的证据**：首次连接失败原因、选轨是否理解、每次失配/误恢复、长休止恢复、音色主观反馈、完成一次完整练习任务的比例。收集最小必要信息，避免在没有隐私方案时上传演奏音频。

**Go/No-Go**：若目标用户不能稳定完成流程，先改连接/引导/曲目数据；不要扩曲库或引入后端掩盖基础问题。

### 阶段 B：选择一条可投资的产品主线

只有阶段 A 通过后，选择其一：

1. **USB MIDI 练习助手**：扩展少量已授权、声部明确的钢琴主导曲目，优先可靠性、曲目数据和练习反馈。
2. **麦克风乐谱跟随研究**：单独建设带标注演奏数据的 benchmark，先报告单旋律、错音、跳段、休止和设备噪声下的结果；在可量化之前不得纳入产品承诺。
3. **高保真音频 vertical slice**：只做一个平台、一首曲目、少量 stem、定义好的拉伸范围与缓存预算。验证通过后再谈批量内容生产。

这些方向可在未来组合，但不能同时作为下一 Sprint 的承诺。

### 阶段 C：扩大试用或商业化前的门槛

- 为每一份资产完成来源、许可、署名和地区/渠道适用性台账；公版作品不自动使后来的 MIDI、排版、录音或音色库也可再分发。IMSLP 也对公版、用户版次和许可证作区分，见其 [Public Domain 说明](https://imslp.org/wiki/Public_Domain) 与 [Licensing Policy](https://imslp.org/wiki/IMSLP%3ALicensing_Policy_and_Guidelines)。这不是法律意见；商业发布前应按目标市场与具体合同核验。
- TestFlight 外部测试和 App 元数据必须如实描述能力、限制与测试重点；Apple 对 beta 与应用审核有独立要求，见 [TestFlight](https://developer.apple.com/testflight/) 和 [App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/)。
- 再决定是否投入内容生产、订阅、账号体系和教师功能。没有重复练习证据前，不预测收入或设定订阅价格。

## 4. 暂停的方向及恢复条件

| 方向 | 当前决定 | 恢复条件 |
| --- | --- | --- |
| Android | 暂停 | iOS USB MIDI 试验有明确价值，且有独立的 Android MIDI/音频验证计划。 |
| 麦克风/OLTW/HMM | 研究储备，不进 beta | 有可复跑 benchmark、目标乐器范围和失效边界。 |
| PDF OMR | 不进 beta | 受控服务已部署，认证与结果访问控制、限流/并发、文件校验、TLS、恶意文件防护、数据删除和真实谱面准确率均有证据。 |
| stem + 时间拉伸 + 动态层 | 不进近期承诺 | 单曲 vertical slice 达到预设延迟、音质、下载与许可门槛。 |
| 教师 SaaS/订阅 | 暂停 | 有反复使用和付费意愿证据，并完成内容权利与支付设计。 |
