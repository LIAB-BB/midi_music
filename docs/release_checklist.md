# 上线前验收清单

本文用于发布或交付 iOS 试用版前的轻量人工验收。自动化测试负责基础契约，本文重点覆盖真实 iPhone、USB MIDI 电子琴、SoundFont、轨道静音和跟随模式。

## 1. 文档定位

适用于每次准备发布或交付试用版前的最后一轮检查。

本文不替代以下自动化质量门禁：

```bash
flutter analyze
flutter test
```

## 2. 验收前准备

### 2.1 代码与依赖

- [ ] 使用干净工作区，或确认待验收改动已经提交 / 明确记录
- [ ] 已运行 `flutter pub get`
- [ ] 已运行 `flutter analyze`
- [ ] 已运行 `flutter test`
- [ ] iOS 验收前已运行 `cd ios && pod install`

### 2.2 设备与测试素材

- [ ] 准备一台 iPhone 真机和一台支持 class-compliant USB MIDI 的电子琴
- [ ] 准备匹配 iPhone 接口的 USB 线或带供电的转接器 / Hub
- [ ] 先在 Xcode 中启用无线调试，避免 Mac 调试线占用 iPhone 的 USB 接口
- [ ] USB MIDI 热插拔、跟随模式和长休止恢复必须使用真机复测
- [ ] 准备一份可导入的有效 MIDI 文件
- [ ] 准备一份无效或异常 MIDI 文件，用于导入失败路径
- [ ] 准备一份包含多轨道和明显长休止段的 MIDI 文件
- [ ] 如需验证首次启动 SoundFont 下载，先清理应用数据或使用首次安装状态

## 5. 详细验收场景

### S1. 首次启动 SoundFont 下载

目的：确认首次运行时音色库准备流程可用，失败时用户知道如何恢复。

前置条件：清理应用数据，或使用首次安装状态启动 App。

步骤：

- [ ] 保持网络可用，启动 App 后观察 SoundFont 状态
- [ ] 首页或播放器页应展示检查中 / 下载中 / 已就绪等状态
- [ ] 下载完成后状态应变为音色已就绪
- [ ] 导入 MIDI 后应能使用 SoundFont 正常播放
- [ ] 断网或阻断下载后重新启动 App
- [ ] 下载失败时应出现失败提示和重试入口
- [ ] 点击重试后不会崩溃，状态能重新进入准备流程

通过标准：音色准备成功后可以播放 MIDI；失败路径有明确提示和重试入口。

### S2. 导入 MIDI

目的：确认用户能从文件系统导入标准 MIDI 文件，并能看到曲目与轨道信息。

前置条件：准备一份有效 MIDI 文件和一份异常 MIDI 文件。

步骤：

- [ ] 点击首页「导入乐谱文件」
- [ ] 选择一份有效 MIDI 文件
- [ ] 导入完成后自动进入播放器页面
- [ ] 播放器标题应显示当前曲目名称
- [ ] 轨道列表应显示可控制轨道
- [ ] 返回首页后尝试导入异常 MIDI 文件
- [ ] 导入异常文件时应显示解析失败提示，而不是崩溃

通过标准：有效文件能进入播放器，无效文件有错误提示。

### S3. 播放 / 暂停 / seek

目的：确认基础播放控制可用，seek 后没有残留长音。

前置条件：已完成 S2，播放器页面已有有效 MIDI 曲目。

步骤：

- [ ] 点击播放，当前时间和进度条开始推进
- [ ] 点击暂停，播放停止推进且没有持续长音
- [ ] 再次播放能从暂停位置继续
- [ ] 拖动进度条进行 seek
- [ ] 使用快进 / 后退按钮进行 seek
- [ ] seek 后播放位置正确更新
- [ ] seek 前后的活动音符应被清理，不应出现卡音或残留长音

通过标准：播放控制稳定，seek 后声音状态正确。

### S4. 设置页调整默认速度

目的：确认设置页能保存默认速度，并影响当前曲目或新导入曲目的初始速度。

前置条件：已导入一首 MIDI，并确认播放器可正常播放。

步骤：

- [ ] 从首页或播放器页右上角进入「设置」
- [ ] 调整「默认速度」滑块
- [ ] 点击「应用到当前曲目」后，当前播放器速度应更新
- [ ] 返回播放器并播放，确认速度变化可感知
- [ ] 重新导入一首 MIDI，新曲目应使用设置中的默认速度
- [ ] 点击「恢复默认」后，默认速度回到推荐值

通过标准：设置值能被保存、应用，并影响新导入曲目的初始速度。

### S5. USB MIDI 发现 / 热插拔

目的：确认电子琴直接连接 iPhone 后，App 能准确展示连接状态。

前置条件：电子琴已开机，准备好 USB 线或转接器。

步骤：

- [ ] 未连接电子琴时，播放器显示「USB MIDI · 未检测到设备」
- [ ] 将电子琴直接连接到 iPhone
- [ ] 页面应显示电子琴的 CoreMIDI 设备名
- [ ] 弹奏按键后 App 不崩溃，电子琴仍由自身扬声器发声
- [ ] 拔出 USB 后，页面恢复未连接状态
- [ ] 重新插入后无需重启 App 即可再次显示设备名

通过标准：连接、拔出和重连状态均正确，App 无需重启。

### S6. 跟随模式打开 / 关闭

目的：确认 USB MIDI 跟随生命周期完整，并且 App 不重复播放钢琴声部。

前置条件：已连接电子琴、导入分轨明确的 MIDI，并确认钢琴轨和伴奏轨没有共享会互相干扰的 channel/note。

步骤：

- [ ] 在轨道列表选择全部钢琴轨（通常包含右手与左手）
- [ ] 打开「跟随模式」开关，App 不应请求麦克风权限
- [ ] 所选钢琴轨全部自动静音，其余伴奏开始播放
- [ ] 弹奏电子琴，伴奏速度可被跟随逻辑调整
- [ ] 关闭跟随模式，播放速度恢复为 1.0x
- [ ] 钢琴轨恢复为开启跟随前的静音状态
- [ ] 多次打开 / 关闭不应崩溃或遗留静音状态

通过标准：跟随可重复进入和退出，钢琴轨不重复发声，用户原始轨道状态可恢复。

### S7. 长休止等待恢复

目的：确认跟随模式遇到长休止时能暂停等待，并在下一次有效起拍后恢复。

前置条件：使用 iPhone 和 USB MIDI 电子琴，导入包含明显长休止的 MIDI 曲目，并选择包含休止后旋律的全部电子琴轨。

步骤：

- [ ] 打开跟随模式并开始播放 / 演奏
- [ ] 当谱面进入长休止区间时，状态应进入等待起拍
- [ ] 伴奏应暂停或停止推进，不应在休止后自动抢跑
- [ ] 休止期间弹错音不应导致明显误恢复
- [ ] 演奏下一个正确起拍音后，状态应恢复实时跟随
- [ ] 伴奏应继续播放并根据演奏速度调整
- [ ] 关闭跟随模式后，等待状态应被清理

通过标准：长休止期间等待用户输入，下一次有效 onset 后恢复播放。
