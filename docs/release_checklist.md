# 封闭试用版验收清单

> 适用范围：当前 iOS USB MIDI 封闭试用版。以 [`product/release_scope.md`](product/release_scope.md) 为准。
>
> 这不是 Android、麦克风跟随、通用 PDF OMR 或完整曲库的发布清单。若这些能力进入范围，必须先更新范围、能力矩阵和本清单。

本文用于发布或交付 iOS 试用版前的人工验收。自动化测试负责基础契约，本文重点覆盖资产、真实 iPhone、USB MIDI 电子琴、固定钢琴轨过滤和跟随模式。若 App 伴奏保留，还必须完成音色库交付验收。

## 1. 文档定位

适用于每次准备发布或交付试用版前的最后一轮检查。它要求留下可追溯的记录，而不是仅凭“我已经试过”判断通过。

本文不替代以下自动化质量门禁：

```bash
flutter analyze
flutter test
```

## 5. 详细验收场景

### S0. 资产与范围核验

目的：确保演示、TestFlight 和构建产物没有把未授权资源或未实现能力带给测试者。

步骤：

- [ ] 对照构建产物、Flutter asset manifest、首页卡片、导入示例和 TestFlight 截图，列出所有随包、下载或展示的 MIDI、PDF、页面图、SF2、图标、字体和音频。
- [ ] 将每项与 [`evidence/asset_manifest.md`](evidence/asset_manifest.md) 对照；只有“已核验”的项可以随本轮分发。
- [ ] 核对 [`evidence/k478_asset_evidence.md`](evidence/k478_asset_evidence.md) 中的来源页、原始包和文件哈希；保存本轮测试所用版本的记录。
- [ ] 确认对外文字没有承诺 Android、麦克风跟随、通用 PDF OMR、AI 伴奏或完整曲库；离线音色只描述为 K.478 当前弦乐候选，不能外推为通用管弦音色库。
- [ ] 确认音色库策略已选定：若输出伴奏，禁止“下载但未固定版本”的实现；若不输出伴奏，禁止保留启动下载或音色库门禁。标为“禁止分发”的 SF2 不在最终 Flutter asset manifest 与 IPA 内。

通过标准：本轮全部资源有可复核证据，且文案与 [`product/capability_matrix.md`](product/capability_matrix.md) 一致。

### S1. 音色库交付路径

目的：验证选定的音色库策略在真实 iPhone 上可以播放，并在失败时不误导用户。

前置条件：已在资产台账中明确选择以下一种策略：随包离线加载，或固定版本、HTTPS 下载、完整性校验和明确失败体验。

步骤：

- [ ] 在首次安装/清理数据的 iPhone 上启动 App，记录实际音色库来源、版本和文件大小。
- [ ] 载入内置 K.478 后确认非钢琴伴奏轨可以正常发声。
- [ ] 若使用下载：验证 URL 为固定版本、下载后进行了预期哈希/大小校验；断网或校验失败时有可理解的提示和重试路径。
- [ ] 若使用随包：在离线状态完成首次播放，并确认实际加载的正是登记文件。
- [ ] 在停止、seek、重新进入播放器后确认没有卡音或错误音色。

通过标准：真实 iPhone 上的实际交付路径与台账相符，并能在正常和失败条件下准确表达状态。

本轮独立候选采用随包 Violin/Cello SF2；根开发 host 的“下载并缓存”实现
不进入候选。不能以 macOS 离线渲染代替 iPhone S1，也不能在官方输入
比对、签名 IPA 检查和真机听音前判定 S1 通过。

### S2. 内置 K.478 载入

目的：确认首轮用户能从首页稳定进入唯一获准、固定分轨的内置曲目。

前置条件：使用干净安装或回到首页状态。

步骤：

- [ ] 点击首页「开始 USB MIDI 排练」
- [ ] K.478 内置 MIDI 载入完成后自动进入演奏台
- [ ] 演奏台标题应显示「K.478 演奏台」
- [ ] 页面明确说明弦乐为小提琴 I / II 与大提琴，钢琴两轨永久留给电子琴
- [ ] 返回首页后确认没有通用文件导入、MusicXML 或 PDF OMR 入口

通过标准：内置 K.478 能进入演奏台，且本轮不暴露范围外导入入口。

### S3. 播放 / 暂停 / seek

目的：确认基础播放控制可用，seek 后没有残留长音。

前置条件：已完成 S2，演奏台已载入 K.478。

步骤：

- [ ] 点击播放，当前时间和进度条开始推进
- [ ] 点击暂停，播放停止推进且没有持续长音
- [ ] 再次播放能从暂停位置继续
- [ ] 拖动进度条进行 seek
- [ ] 使用快进 / 后退按钮进行 seek
- [ ] seek 后播放位置正确更新
- [ ] seek 前后的活动音符应被清理，不应出现卡音或残留长音

通过标准：播放控制稳定，seek 后声音状态正确。

### S4. 调整当前会话速度

目的：确认演奏台速度按钮能调整当前 K.478 会话的播放速度。

前置条件：已载入 K.478，并确认播放器可正常播放。

步骤：

- [ ] 在演奏台依次选择 0.50×、0.75×、1×、1.25×
- [ ] 每次选择后对应按钮状态应更新
- [ ] 播放并确认推进速度变化可感知
- [ ] 返回 1× 后确认当前会话恢复原速
- [ ] 退出并重开 App 后允许恢复 1×；本轮不承诺持久化默认速度

通过标准：当前会话的速度选择和实际播放推进一致；不存在无法进入的设置页步骤。

### S5. USB MIDI 发现 / 热插拔

目的：确认电子琴直接连接 iPhone 后，App 能准确展示连接状态。

前置条件：电子琴已开机，准备好 USB 线或转接器。

步骤：

- [ ] 未连接电子琴时，播放器显示「CoreMIDI · 未检测到设备」
- [ ] 将电子琴直接连接到 iPhone
- [ ] 页面应显示电子琴的 CoreMIDI 设备名
- [ ] 弹奏按键后 App 不崩溃，电子琴仍由自身扬声器发声
- [ ] 拔出 USB 后，页面恢复未连接状态
- [ ] 重新插入后无需重启 App 即可再次显示设备名
- [ ] 若系统同时存在虚拟或网络 MIDI 端点，确认各端点的字节流不会互相拼接；本轮仍只以直接连接的 USB 电子琴作为通过依据

通过标准：连接、拔出和重连状态均正确，App 无需重启。

### S6. 跟随模式打开 / 关闭

目的：确认 USB MIDI 跟随生命周期完整，并且 App 不重复播放钢琴声部。

前置条件：已连接电子琴、已载入候选内置 K.478，并确认固定钢琴轨 4/5 与伴奏轨 1/2/3 的 program/channel 映射与资产证据一致。

步骤：

- [ ] 打开「跟随模式」开关，App 不应请求麦克风权限
- [ ] 固定钢琴轨 4/5 的输入进入跟随逻辑，但其 Program Change、Note On、Note Off 永不发送到 App 音频引擎
- [ ] 弹奏电子琴，时间线速度可被跟随逻辑调整；若本轮启用 App 伴奏，同时确认其余伴奏轨正常播放
- [ ] 关闭跟随模式后输入订阅停止，并恢复开始跟随前由用户选择的当前会话速度
- [ ] 多次打开 / 关闭不应崩溃、重复订阅或令 App 播放钢琴声部

通过标准：跟随可重复进入和退出，固定钢琴轨始终不由 App 发声，USB 输入订阅能正确释放。

### S7. 长休止等待恢复

目的：确认跟随模式遇到长休止时能暂停等待，并在下一次有效起拍后恢复。

前置条件：使用 iPhone 和 USB MIDI 电子琴，载入包含明显长休止的 K.478；跟随目标固定为钢琴轨 4/5。

步骤：

- [ ] 打开跟随模式并开始播放 / 演奏
- [ ] 当谱面进入长休止区间时，状态应进入等待起拍
- [ ] 时间线应暂停或停止推进，不应在休止后自动抢跑
- [ ] 休止期间弹错音不应导致明显误恢复
- [ ] 演奏下一个正确起拍音后，状态应恢复实时跟随
- [ ] 时间线应继续推进并根据演奏速度调整；若本轮启用 App 伴奏，确认伴奏同步恢复
- [ ] 关闭跟随模式后，等待状态应被清理

通过标准：长休止期间等待用户输入，下一次有效 onset 后恢复播放。

### S8. 试用说明与反馈闭环

目的：让测试者知道如何完成目标任务、哪些情况不在承诺范围，以及如何报告问题。

步骤：

- [ ] TestFlight 说明明确仅支持 iOS、class-compliant USB MIDI 电子琴与当前获准曲目。
- [ ] 说明电子琴自身发声、USB 热插拔必须在真机验证；App 只播放固定弦乐轨 1/2/3，不提供通用选轨。
- [ ] 列出已知限制：精确 MIDI 匹配不保证错音/跳段/复调，PDF OMR 不在本次试用范围。
- [ ] 提供反馈入口，并要求反馈包含 App 版本、iPhone/iOS、电子琴型号、连接方式、曲目与复现步骤；不要默认收集演奏音频。
- [ ] 明确出现资产/授权、音色库、崩溃或跟随严重失配问题时的暂停分发与回滚负责人。

通过标准：测试目标、限制、反馈和暂停条件对测试者可见且可执行。

## 6. 发布判定

- [ ] 自动化质量门禁全绿
- [ ] S0、S2-S8 全部通过；S1 在启用 App 伴奏时不可豁免。S0（资产）、S5-S8（真机输入、跟随与试用说明）不可豁免，任一失败均阻止本轮分发
- [ ] iPhone 真机上至少完成一次 USB MIDI 热插拔、跟随模式和长休止恢复验收
- [ ] 资产台账、测试说明和验收记录已附到本次构建/commit；若启用 App 伴奏，附上音色库记录
- [ ] 已定义严重问题（资产权利、启用时音色不可用、崩溃、明显误跟随）出现时的暂停测试和回滚方式

满足以上条件后，才可以进入受控的小范围 TestFlight 试用；这不等于公开 App Store 发布就绪。
